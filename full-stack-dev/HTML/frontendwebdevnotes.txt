
The internet ?

The internet is made up of interconnected computers.
When we search a website, the request from the web browser is sent to the DNS through our internet service providers. 
The DNS is like a phonebook, it keeps records of the all the addresses of webservers. 
The web servers are like 24/7 open libraries that contain all data imaginable.
The DNS returns the address of the particular web servers and sends the request throught the ISP to the web browser.
The client then receives the address of the web server and looks up the IP address of the web server in the internet
and the web server responds back with the data sending it through the internet.
every computer connected to the internet has an IP addresses associated with it and it is recorded in the DNS.
the client computer sends the request the server computer receives the request and responds to the client request.


How do websites actually work?
when we google the address we obtained from the DNS lookup we get back the requested data inform of three code files, HTML, CSS and JavaScript
The page rendered by a web server contains is made up of the following:

HTML file - that has the structure of the file,
the paragraphs, text and headers as well as different elements like button and containers.

The CSS file that is responsible for styling the website,
defines the color of different elements, the shape and where the different elements are placed in the page.

JavaScript file that is responsible for the functionality of the website.
It ensures all the elements are interactive and functional.
