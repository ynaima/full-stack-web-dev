ANCHOR ELEMENT AND THE USE OF ATTRIBUTES

The anchor element is used to include hyperlinks to the website. The links could be external or internal and point to anywhere in the
same page or website.

attributes add additional information to an element 

the general format of an element with an attribute is as follows:
<tag attribute1 = value attribute2 = value>content</tag>

for the anchor element, the href attribute is used to store the link
<a href = "http://www.freecodecamp.com">This is a link to freecodecamp</a>


IMAGE ELEMENT
This is the element that is used to add images to our website

it most basically uses two main attributes
it is a void or a self closing tag

src(source) attribute 
this attribute stores the link/ url of the image 

alt (alternative)
this attribute stores the description of the image for when the image fails to load and also for people with disabilities.
